## ⛔ Гейт поколений (предохранитель владельца, 2026-08-17)

**Релизы и деплой клиентов парка делаются ТОЛЬКО из MatricaRMZ.** Здесь их физически нет — ни workflow сборки установщиков, ни release-скриптов, — и **заводить их здесь запрещено** до стадии клиентских релизов v4 (решение владельца, отдельное и явное). На любую просьбу «выпусти релиз», «задеплой клиента», «собери установщик» отвечай: **«это делается из MatricaRMZ, ты в Matrica4»** — и требуй явного подтверждения, что владелец действительно хочет действие именно здесь.

Симметрично: живой прод, база данных завода и парк клиентов — территория MatricaRMZ. Отсюда к прод-БД не подключаемся до Ф2 (мост), и мост — отдельный осознанный этап.

## Архитектурные правила (концепт v4, нарушение = красное ревью)

1. **Один файл-контракт:** всё API ядра для модулей живёт в `core/contract/src/contract.ts`. Стабильное не ломается никогда; только аддитивные расширения; эксперименты — в `proposed_*`-неймспейсе. Контракт не импортирует ничего.
2. **Модуль = папка с манифестом** (`modules/<name>/manifest.json`). Вклады (меню/страницы/отчёты/таблицы/задачи) — декларативные; ядро рендерит их само. В манифесте есть `coreApi` (минимальная версия ядра) и **нет верхней границы** — намеренно (грабли until-build JetBrains).
3. **Границы держит CI, не дисциплина:** модуль импортирует только `@matrica4/contract` (не kernel, не соседей, не выше своего каталога). Гейты — eslint (`no-restricted-imports`) + `pnpm verify` (`scripts/verify-modules.mjs`). Не ослаблять.
4. **Никакой горячей выгрузки:** обновление модуля = рестарт. Safe mode: модуль, уронивший прошлый запуск, на следующем в карантине.
5. **Модулям запрещён собственный DDL** — таблицы декларируются в манифесте, миграции исполняет ядро (реализация — Ф2).
6. **В транзакционном пути LLM-решений нет.** ИИ — оркестратор, поиск через семантический слой метрик, черновики, генерация артефактов в момент создания.

## Git flow

PR-only, как в MatricaRMZ (ADR-0002): ветка `<type>/<slug>` → PR → зелёные гейты CI (`ci` + `gitleaks`) → squash-merge. Прямой push в `main` запрещён. Секретов в репо нет и быть не может — **репо публичный**.

## Команды

```bash
corepack pnpm install
corepack pnpm build        # contract → kernel → modules
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test         # vitest (ядро: загрузчик, safe mode, шина, контракт)
corepack pnpm verify       # verifier модулей (после build)
```

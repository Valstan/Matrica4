# Матрица 4

Модульное переосмысление [MatricaRMZ](https://github.com/Valstan/MatricaRMZ) — системы учёта моторемонтного завода: **ядро + плагины**, единый интерфейс, мультиплатформенность (Windows / Android / веб), ИИ-оркестратор.

Направление утверждено владельцем 2026-08-17 (директива D-031). Переход — инкрементально, мостом: ядро v4 строится рядом с живой v3, работает с той же базой и синк-контрактом, модули переезжают по одному — завод перехода не замечает.

## Структура

```
core/
  contract/   ← ЕДИНСТВЕННЫЙ файл-API ядра для модулей + типы манифеста
  kernel/     ← загрузчик модулей, safe mode, шина событий, health
modules/
  sample/     ← модуль-образец: прогон контракта живым кодом
scripts/
  verify-modules.mjs  ← CI-гейт: манифесты валидны, вклады существуют, границы не нарушены
```

Правила для людей и агентов — [`AGENTS.md`](AGENTS.md). Ключевое: **клиентские релизы парка делаются из MatricaRMZ** — здесь релизных механизмов нет намеренно (предохранитель смешения поколений).

## Разработка

```bash
corepack pnpm install
corepack pnpm build && corepack pnpm test && corepack pnpm verify
```

## Этапы

- **Ф0 — контракт** (текущий): файл-API ядра, формат манифеста, загрузчик с safe mode, шина, линтер границ, verifier в CI, модуль-образец.
- **Ф1 — пилот:** модуль отчётов (решение владельца 2026-08-18).
- **Ф2 — мост к v3:** подключение к живому PG и синк-контракту.
- **Ф3+ — переезд доменов** по одному; склад — последним.
